# GrowCalculate

Grow Castle 1.50.14 planner.

## Structure

- Unlimited Wave planner.
- Checkpoints: 1,000 / 2,500 / 5,000 / 7,500 / 10,000.
- Post-10,000 scaling.
- 1 Leader slot.
- 12 Hero slots.
- Stone is a Hero.
- Normal Tower slots: 4.
- Stone promoted: 6 Tower slots.
- Town: 3 slots.
- Castle Defense: 3 top + 1 bottom.
- Treasures: 5 slots.
- Tower levels are stored separately.
- Tower equipment database is prepared for version 1.50.14.

## Important

The numerical level ratios in this planner are configurable planning targets, not official game formulas.
