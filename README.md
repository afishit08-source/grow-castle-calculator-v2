# GrowCalculate
Grow Castle 1.50.14 planner.
## Features
- Wave unlimited.
- Checkpoints: 1,000 / 2,500 / 5,000 / 7,500 / 10,000.
- Post-10,000 scaling.
- 12 Hero slots.
- Leader is separate from Hero slots.
- 3 Town slots.
- 4 Castle Part slots.
- 4 normal Tower slots.
- 6 Tower slots when Stone is active.
- Tower levels stored separately in `tower_levels_2026.json`.
- Worm/Thorn Worm are treated as Towers.
